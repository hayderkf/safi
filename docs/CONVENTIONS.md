# CONVENTIONS — أعراف الكود (Safi)

## عام
- **العربية أولاً + RTL** في كل واجهة. كل نصّ عبر `labelTranslations{ar,en}` (لا نصوص مزروعة).
- **لا أسرار في الكود**: `.env` + إدارة أسرار. لا توكنات/كلمات مرور في git.
- **العقد قبل التنفيذ**: أي تغيير على IR/API يُحدَّث في `docs/IR_SCHEMA.md` أولاً.

## التسمية
- معرّفات الحقول: `snake_case` نصّية فريدة.
- ملفات/مجلدات: `kebab-case` (الويب)، `snake_case` (Python).
- جداول DB: واضحة بالإنجليزية، بلا Foreign Keys صارمة إلا عند الحاجة؛ فهارس على مفاتيح البحث.

## الباك إند (Python/FastAPI)
- Python 3.12، `venv`، `ruff` + `black`. Pydantic v2 للنماذج/التحقّق.
- **لا SQL نصّي** — SQLAlchemy/parameterized. هجرات عبر Alembic.
- كل نقطة API موثّقة (OpenAPI تلقائي).

## الويب (Next.js/TS)
- TypeScript صارم. مكوّنات صغيرة. المنطق المشترك في `packages/shared-web`.
- مُصيِّر الاستمارة يُبنى من IR لا يدوياً.

## الذكاء
- كل استدعاء عبر **طبقة تجريد المزوّد** (لا نداء Ollama مباشر في منطق الأعمال).
- كل مخرَج: تحقّق من المخطط + **مصدر + درجة ثقة**، واعتماد بشري للقرارات.
- موجّهات (prompts) في ملفات مستقلّة قابلة للإصدار، مع مجموعة eval.

## الجودة
- اختبارات لكل خدمة قبل اعتبارها منجزة. لا «منجز» مع فشل اختبار.
- التزام صغير وواضح (commits)؛ رسائل بالعربية أو الإنجليزية بثبات.
- راجع **أرضية التكافؤ** (وثيقة المكدّس §8) قبل إغلاق أي مرحلة.
