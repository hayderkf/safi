# BUILD_PLAN — خطة بناء Safi (مراحل)

المبدأ: **هيكل ماشٍ أولاً** (أنحف مسار كامل يعمل)، ثم توسّع رأسي. كل مرحلة تنتهي بشيء قابل للتشغيل والاختبار.

## المرحلة ٠ — السقالة والعقود
- بنية المجلدات (apps/web, packages/shared-web, backend, ai, infra, docs).
- تعريف **العقد**: `docs/IR_SCHEMA.md` (مخطط الاستمارة) + هيكل API (OpenAPI) + قواعد DSL.
- طبقة **تجريد المزوّد** للذكاء (واجهة موحّدة → Ollama الآن).
- إعداد Postgres + pgvector محلياً.

## المرحلة ١ — خدمة توليد الاستمارات (تثمير الـ PoC)
- FastAPI: `POST /forms/generate` (وصف عربي → مخطط IR).
- يغلّف Ollama (`qwen2.5:14b`) + **تحقّق Pydantic من المخطط + حلقة إصلاح** + few-shot لضمان JSON صالح.
- اختبار على حالات الـ PoC (stepper/جدول/مصفوفة/تكرار/شرط).

## المرحلة ٢ — التخزين الهجين والـ CRUD
- جداول: `forms`, `form_fields` (تعريف، IR في JSONB), `submissions` (JSONB) + Views تحليلية مولّدة.
- API عام آمن (parameterized) لـ CRUD.

## المرحلة ٣ — الويب: المُصيِّر والباني والتعبئة
- `packages/shared-web`: مُصيِّر يبني واجهة من IR (٢٧+ نوع) + محرّك القواعد (السلوكيات الخمسة).
- `apps/web`: باني الاستمارات + شاشة التعبئة + الإرسال. (offline-first لاحقاً.)

## المرحلة ٤ — البيانات الساندة والإسناد
- جداول القوائم الساندة (هرمية/متتالية) + ربط حقول الاختيار بها (بديل عناصر AI النائبة).

## المرحلة ٥ — الهوية والصلاحيات وسير المراجعة
- RBAC/ABAC + مستخدم خارجي بلا حساب + مراجعة/اعتماد متعدد المستويات.

## المرحلة ٦ — البحث الدلالي
- embeddings (BGE) + pgvector + بحث هجين (نصّي + دلالي).

## المرحلة ٧ — محرّك سير العمل
- ReactFlow (محرّر) + Temporal (تنفيذ) + ربط المهام بالاستمارات.

## المرحلة ٨ — الذكاء المتقدّم
- قراءة المستندات (OCR/IDP) + تحليل الصور (Vision) + تحليلات تنبؤية + محرّك الفجوة (معيار↔واقع).

## المرحلة ٩ — التغليف والنشر
- Docker Compose: نسخة معزولة لكل مؤسسة (on-prem)، + MinIO + Temporal.

> أرضية التكافؤ تُراجَع في كل مرحلة (القائمة في وثيقة المكدّس §8).
