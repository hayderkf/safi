# DECISIONS & JOURNEY — الرحلة والقرارات والنقاط المضيئة

## ١) كيف بدأ
نظام IMS قديم (Flutter + Node + Postgres): منصة استمارات ديناميكية ناضجة لكنها **ثابتة**، وبها نقاط ضعف موثّقة (راوتر عام ببناء SQL نصّي = خطر حقن، أسرار في الكود، تخزين إجابات EAV ضعيف للتحليلات، محاولة AI خجولة عبر Gemini). الحدود التي بلغها القديم مفصّلة في `IMS_Current_Architecture.md` و`IMS_FormBuilder_DeepDive.md`. الهدف: نظام جديد **لا يقلّ عنه** ويتجاوزه ذكاءً.

## ٢) كيف تطوّرت الرؤية
- الاستمارة ليست المركز، بل **أداة قياس**. المركز: جهة خاضعة لها تاريخ + بيانات أساسية + دورة حياة.
- ظهر **المبدأ الناظم: «معيار ↔ واقع»**، يتكرّر داخلياً (التوأم) وخارجياً (الامتثال).
- تبلورت الموديلات: **الاستمارات (نواة مستقلّة)** + **التوأم المؤسسي** (موثّق de jure + فعلي de facto عبر المصارحة السردية + محرّك فجوة) + **متابعة الالتزامات/الامتثال (GRC)** + **طبقة ذكاء جامعة**.
- التموضع: **منصة تقييم ومتابعة قابلة للبرمجة**؛ GRC مجرّد عمودي واحد منها (وM&E عمودي آخر).

## ٣) القرارات المفصلية (و«لماذا»)
- **تخزين هجين** (JSONB + Views مولّدة) — مرونة + أداء تحليلي، بلا انفجار جداول.
- **سيادة البيانات** (مصارف/رقابة) → نموذج **محلي on-prem** خلف **طبقة تجريد مزوّد**.
- **لا Flutter**؛ كل منصة native بتخصصها، نبدأ بالويب (Next.js). الناتج: **عقد مشترك لا كود مشترك** (IR + API + DSL مصدرها الباك إند).
- **الباك إند Python/FastAPI**؛ قاعدة PostgreSQL 17 (+ pgvector لاحقاً).
- **النموذج: qwen2.5:14b** — اختير **بالدليل عبر PoC** (طابَق جودة Gemma 4 26b/31b في البنى الصعبة بنحو ضعف السرعة، Apache 2.0). 31b ممتاز لكنه بطيء (السقف لا التشغيل).
- **سير العمل:** ReactFlow (محرّر) + **Temporal أساسي مع شرط رجوع** إلى statechart+طبقتنا عند ضعف الأداء (DR-1).
- **منافذ Safi:** الباك إند 8601، الواجهة 3601.

## ٤) النقاط المضيئة (مبادئ تحكم البناء)
- **الاستمارات نواة مستقلّة** تعمل و«التوأم=صفر» (مثال: لجنة باصات تولّد استمارة لسائق متعاقد — لا علاقة بالتوأم). الاعتماد أحادي الاتجاه.
- **الإسناد قبل كل شيء (Provenance):** كل معلومة/مخرَج تحمل مصدراً ودرجة ثقة وإصداراً — هذا «نسيج الثقة» الذي يفرّق النظام عن «بانٍ استمارات ذكي».
- **كبح الهلوسة لا منعها:** إسناد مغلق + «يرفض عند الجهل» + إنسان في الحلقة.
- **الذكاء يعلو المحرّكات:** التعزيز بالـ AI طبقة فوق محرّك سير العمل/التخزين، لا داخل نواته.
- **لا تبنِ المحرّكات الصعبة الشائعة** (مزامنة، ورك فلو، RAG) — تبنَّ ناضجاً وابنِ ما يميّزك.
- **قياس لا انطباع:** قرار النموذج حُسم بـ eval فعلي، لا بالحدس.
- **«الأحرف» ≠ «الأعقد»:** لمؤسسة واحدة on-prem، البساطة احترافية.
